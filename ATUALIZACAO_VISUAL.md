# Atualização visual — Bom Corte Salões

A identidade visual foi atualizada em todo o aplicativo para uma aparência mais executiva e premium:

- Azul-marinho profundo como base estrutural.
- Dourado/champagne como cor de destaque.
- Fundo claro neutro na área de conteúdo.
- Verde preservado para indicadores positivos.
- Vermelho preservado para alertas/ações destrutivas.
- Redução de brilhos e efeitos neon excessivos.
- Ícones, imagens, funcionalidades, navegação e estrutura de dados foram preservados.

A alteração foi aplicada globalmente aos componentes existentes, não somente ao Dashboard.
